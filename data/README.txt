このフォルダに走行データを置くと、アプリの起動画面から選べるようになります。

1. manifest.example.json を manifest.json にコピー
2. 走行データ(zip/csv)をこのフォルダに置く
3. manifest.json の sessions[].files にファイル名を書く

"auto": true を付けたセッションは起動時に自動で読み込まれます。
URL の末尾に ?s=1 や ?s=美浜 を付けると、そのセッションを指定して開けます。

【重要】
・http(s) で配信されている場合のみ動作します（GitHub Pages / CDAを起動.bat）。
  index.html をダブルクリックした file:// では、ブラウザの制約で動きません。
・公開リポジトリに置いたファイルは誰でもダウンロードできます。
  GPSログを公開したくない場合は、非公開リポジトリ + Cloudflare Pages 等をご検討ください。
・メーカー製のコースデータ(.pth/.bin)を公開リポジトリに置くのは再配布にあたります。
